Reference order (13 phases)

The five rules. A project is not finished until all five are true.

  1. Real data, never synthetic. Kepler light curves, Celestrak TLEs, JPL Horizons, Sentinel-2, Gaia, NOAA.
  2. Validated against a reference. Ship an error plot against ground truth and state the tolerance you reached.
  3. Tested and continuously integrated. pytest or ctest, a GitHub Actions workflow, a green badge.
  4. Documented for a stranger. Physics, method, assumptions, limitations, one command that regenerates every figure.
  5. Published where a recruiter can reach it. Streamlit, PyPI, crates.io, or Zenodo with a DOI. A private repo is not a portfolio.
